# AI-Based Career Recommendation System

## About the Project
This is a machine learning-based web application that recommends suitable career options based on a student's skills and interests.

The project is developed using Python, Flask, and Scikit-learn.

## Features
- AI-based career prediction
- Top 3 career recommendations
- Skill analysis
- Skill gap analysis
- Personalized career roadmap
- User-friendly web interface

## Technologies Used
- Python
- Flask
- Machine Learning
- Scikit-learn
- Pandas
- HTML
- CSS

## How to Run the Project

1. Install Python.
2. Install the required libraries:

   `py -m pip install flask pandas scikit-learn joblib`

3. Train the model:

   `py train_model.py`

4. Start the application:

   `py app.py`

5. Open this address in your browser:

   `http://127.0.0.1:5000`

## Project Purpose
The purpose of this project is to help students explore possible career paths based on their skills and interests.
